## Versioning

Each report carries a version stamp in its footer and in an HTML comment at the
top of the file.

- **Report version** — bumps whenever the underlying data changes: a new quarter
  is reported, a material corporate event lands, or a factual error is corrected.
- **Template version** — the report layout the file conforms to.
